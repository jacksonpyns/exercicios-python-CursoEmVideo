Ao longo do curso, fui desenvolvendo os exercícios juntamente com as aulas, colocando em prática os conceitos apresentados e construindo gradualmente minha base em **Python e lógica de programação**.

## 🚀 Sobre o projeto

Este repositório reúne os exercícios que desenvolvi durante meus estudos de Python com o **Gustavo Guanabara**, do canal **Curso em Vídeo**.
